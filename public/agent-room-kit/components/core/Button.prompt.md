Primary call-to-action button for the desk; solid red for commit actions, outline for neutral.

```jsx
<Button variant="primary" iconRight={icon}>Send Quote to Client</Button>
<Button variant="secondary">Export Quote</Button>
<Button variant="ghost" size="sm">Save to Watchlist</Button>
```
Variants: primary · secondary · ghost · danger. Sizes: sm · md · lg. Props: icon, iconRight, disabled, fullWidth.
