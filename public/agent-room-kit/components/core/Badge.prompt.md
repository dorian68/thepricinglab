Compact badge / tag chip / status pill driving product tags, confidence, risk and workflow state.

```jsx
<Badge kind="directional">Directional</Badge>
<Badge kind="high">High</Badge>
<Badge kind="approved" dot>Approved</Badge>
<Badge tone="amber" variant="outline">AMBER</Badge>
```
Pass kind (directional/balanced/hedge/structured/data-export/high/medium/approved/live/in-progress/locked) or tone (red/green/amber/purple/blue/cyan/neutral). variant: soft · outline · dot.
